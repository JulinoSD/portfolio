Função deste espaço

Neste espaço você vai encontrar todas as minhas práticas com as linguagens de programação web como HTML5, CSS3, e Javascript, tudo desenvolvido do zero, acompanhado com um design legal e muito consumo de API e API REST e boas práticas de programação, vais encontrar também cada repositório (que for público) para replicar, melhorar, ou mesmo dar sua opinião no meu projeto. Sou entusiásta quando se fala de programação, como Engenheiro Eletricista meu foco está em projetos de Engenharia Biomédica, portanto tenho trabalhado as minhas habilidades para outras linguagens de programação, atualmente estudo C++ para processamento de imagens médicas e projetos de engenharia médica, porque ela me facilita a não perder muita memória e ter eficiência no processamento em tempo real, e também compartilho este conhecimento com a linguagem Python, a linguagem Rust é muito interessante para mim também, já estudei, porém ainda não tem o tanto de conteúdo que eu venha a precisar hoje para trabalhar no que estou querendo. A linguagem Julia é muito boa também, principalmente para simulação de flúidos. Em breve alguns projetos irão figurar por aqui também, seguind o mesmo padrão, interface gráfica bem trabalhada e o máximo de profissionalismo e boas práticas.
